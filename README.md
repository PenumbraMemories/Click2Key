# 猫玖键映板 1.0.0 · 便携标准版

Windows 单机按键映射工具。支持双向按键互换、按键触发鼠标点击/按住/滚轮，并提供蓝粉主题与暗色模式。

## 使用

解压便携包到可写目录，双击 `猫玖键映板.exe`。无需安装 .NET、无需联网。配置自动保存到同目录的 `猫玖-settings.json`，复制整个文件夹即可迁移。全局总开关键默认为 `Tab`，可以在窗口右上角重新指定。程序最小化后始终保留在 Windows 普通任务栏，单击任务栏中的猫娘图标即可恢复窗口，不使用右下角隐藏托盘。普通任务栏图标会自动切换状态：猫耳竖起并带绿色对勾表示映射已开启，彩色猫娘耷拉耳朵睡觉并带红色减号表示已停止。程序文件和新建快捷方式的默认图标为启用状态的 Q 版猫娘图；启动后底部普通任务栏按钮按实际映射状态切换为启用或停用的完整 Q 版图。旧快捷方式若仍指向旧版程序，请重新创建。程序仅允许一个实例运行；再次启动会直接唤醒已有窗口。关闭程序会释放模拟按键并卸载全局监听。

默认映射：数字行 `1` 短按左键/长按保持左键，`3` 短按右键/长按保持右键，`2` 向上滚轮，`4` 向下滚轮。

若将文字键绑定为鼠标动作，映射开启时该键会被拦截，无法用于打字。同一按键不能同时用于鼠标映射、互换或总开关键。目标程序以管理员权限运行时，可能需要以相同权限启动本软件。

## 构建

```powershell
dotnet publish Click2Key.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -o ..\猫玖标准便携版
```

项目使用 .NET 8 WPF 和本机 Windows 输入 API。所有设置只存本地，不收集按键内容。界面使用随程序提供的 Noto Sans SC 字体；许可见 `字体许可-OFL.txt`。
